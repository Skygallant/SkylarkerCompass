
### Adds dynamic exploration to the game be providing the player with a, much longer range, "ping" system

*To run the script you need to install Python. To do so please visit: https://www.python.org/downloads/windows/*

*If the script identifies a missing module you can use pip install {module} to install it. This may need to be done for several modules*

Use /showlocation with the script running, and while planetside, to scan the surrounding area up to a 10km (configurable) radius. Your compass will return the 3 (configurable) closest Points of Interest. The script requires two database files which are automatically downloaded and stored next to the script. To update the database files, simply delete them and the script will download new ones.
